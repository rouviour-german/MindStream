# MindStream Blog
> A modern, lightning-fast personal blog platform built with Next.js 14 and MicroCMS.

![MindStream Blog Showcase](https://github.com/user-attachments/assets/ecc00e3d-79e5-4066-a6f2-72e82d5f24e2)

## 🚀 Overview
MindStream Blog is a high-performance blog platform designed for speed and simplicity. By utilizing Static Site Generation (SSG) with Next.js 14, it ensures that your content is always fast, SEO-friendly, and accessible. The integration with MicroCMS allows for seamless content management without the overhead of a traditional backend.

## ✨ Features
- **Static Site Generation (SSG)**: Optimized build-time page generation for extreme speed.
- **Headless CMS Integration**: Easy and intuitive content management using MicroCMS.
- **SEO Ready**: Built-in SEO optimizations to ensure your voice is heard.
- **Responsive Design**: A beautiful, minimalist UI that looks great on any screen.
- **Modern Tech Stack**: Leveraging the latest features of Next.js 14 and TypeScript.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router / SSG)
- **CMS**: MicroCMS (Headless)
- **Library**: React, TypeScript
- **Styling**: Sass (SCSS), normalize.css

## 📦 Installation
Clone the repository and install the dependencies:
```bash
npm install
```

## 💻 Usage
Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
